# keykick

Браузерная игра для ребёнка 10 лет: клавиатурный тренажёр с футбольной обёрткой.
Учебная сессия — матчдэй, урок печати — тайм, задача — пенальти, награда — футбольная форма
в коллекцию. Цели: слепая печать десятью пальцами и уверенная работа с олимпиадными интерфейсами
(числа, дроби, несколько полей, списки, перетаскивание).

**Играть:** https://iliasa101.github.io/keykick/ (в разработке)

Все клубы, лиги, игроки и формы — выдуманные. Графика и звук частично сгенерированы ИИ (Magnific).

## Разработка

```bash
npm ci
git config core.hooksPath .githooks
npm run dev      # игра на localhost
npm run check    # типы, линтер, тесты, сборка — то же, что CI
```

Vite + Vue 3 + TypeScript. Прогресс хранится только в браузере (localStorage), сервера нет.
